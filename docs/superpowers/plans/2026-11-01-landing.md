# Главная страница: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Создать главную страницу в существующей дизайн-системе через Hallmark.

**Architecture:** LandingPage использует чистое расчётное ядро, фиксированный пример и существующий SummaryCards. Клиент и пререндер показывают одну страницу; калькулятор и ссылки на расчёт сохраняются.

**Tech Stack:** React, TypeScript, React Router, Tailwind, CSS, Vitest.

**Spec:** docs/superpowers/specs/2026-11-01-landing-design.md

## Global Constraints

- Geist, светлая изумрудная палитра, семантические CSS-переменные.
- Без банковских обещаний и вымышленного домена.
- Ядро и UI калькулятора не меняются.
- Работа в текущей dev/ui: пользователь проверяет результат в этом проекте; без коммитов, изменения SEO.md сохраняются.

## Review Focus

- `/?s=` с пустой или неверной строкой должен доходить до обработки калькулятора, без потери параметров.
- Пререндер `/` и гидратация должны содержать одинаковую главную.
- Переход в калькулятор не меняет уже введённые пользователем значения.
- В 375px отсутствуют горизонтальное переполнение и потеря действия.
- Логотип возвращает домой, пункт «Расчёт» не активен на главной.
