# Стартовая страница «Ипотека — прозрачно»

Пользователь одобрил Hero с заголовком «Ваша ипотека. В понятных цифрах.», примером расчёта, возможностями и переходом к калькулятору.

## Решение

Главная `/` представляет инструмент; `/calculator` остаётся рабочим калькулятором. Сохраняются Geist, светлая изумрудная палитра и существующая навигация. Вместо новой темы Hallmark наследует систему проекта. Аудитория: человек, планирующий ипотеку; основное действие: рассчитать свои условия. Тон спокойный и предметный.

Рассмотрены статичная обложка и рабочий пример. Выбран пример с настоящим расчётным ядром и существующим SummaryCards: цифры объясняют продукт и соответствуют калькулятору. Ни ставки банков, ни отзывы не добавляются. Условия демонстрационные, из DEFAULT_LOAN.

Композиция: Hero → влияние досрочного погашения на пример → график, сравнение и экспорт → локальное хранение и переход к своему расчёту. Общий футер завершает страницу. Без фотографий: материалом служит сам продукт.

## Ограничения

Ядро расчётов и UI калькулятора не меняются. Старые ссылки `/?s=...` открывают калькулятор с исходной строкой параметров. Главная имеет одинаковый контент при пререндере и в браузере; отдельные метаданные без вымышленного домена. Телефон: одна колонка, доступные кнопки и видимый фокус. Анимация не требуется.

Build, lint, все тесты; готовый HTML главной; основной переход, возврат по логотипу, старая ссылка; проверка desktop/mobile, отсутствия переполнения и ошибок браузера.
