# План: ипотечный калькулятор (SPA, личный инструмент)

> Утверждён пользователем 2026-09-13. Документ-ориентир для реализации; прогресс отмечать в чекбоксах этапов.

## Зафиксированные решения (из ответов пользователя)
- **Продукт:** личный инструмент, без SEO и аккаунтов. SPA, все расчёты в браузере, сервера нет.
- **Стек:** React + TypeScript (сборка Vite).
- **Рынок:** только РФ — ₽, аннуитетные и дифференцированные платежи, пресеты ставок льготных программ (семейная, IT и т.п.) с ручным редактированием.
- **Досрочные:** разовые (месяц + сумма) и регулярная ежемесячная надбавка; для каждого — стратегия «уменьшить срок» или «уменьшить платёж».
- **Без** страховок, комиссий, налоговых вычетов — чистый график.
- **Сохранение/обмен:** ссылка-шаринг, экспорт XLSX, экспорт PDF, история в localStorage.
- **Сравнение:** 2–3 сценария рядом.
- **Графики:** остаток долга (линейный), состав платежа по месяцам (столбчатый), структура выплат (круговая).
- **Оформление:** светлая + тёмная тема, по умолчанию системная. Деплой пока локальный.

## Стек (с обоснованием)
| Слой | Выбор | Почему |
|---|---|---|
| Сборка | Vite 7 + React 19 + TS | быстрый дев-сервер, статический билд |
| UI | Tailwind CSS 4 + shadcn/ui | готовые доступные компоненты, темы из коробки |
| Состояние | Zustand (+persist для истории) | минимальный бойлерплейт |
| Графики | Recharts | line/bar/pie, декларативный React-подход |
| XLSX | exceljs | форматирование ячеек, ₽-формат, итоги |
| PDF | печатная страница + `window.print()` (Сохранить как PDF) | векторное качество без тяжёлых зависимостей |
| Ссылка | lz-string (compressToEncodedURIComponent) | весь расчёт в одном коротком параметре `?s=` |
| Роутинг | react-router (2 маршрута) | калькулятор `/` и печатный отчёт `/report` |
| Качество | Biome (lint+format), Vitest | один инструмент вместо ESLint+Prettier |

Точные актуальные версии библиотек уточнять через **context7** при инициализации (правило из AGENTS.md); при недоступности — firecrawl по официальной документации. При работе с UI использовать скиллы `ui-styling` / `ui-ux-pro-max`; после инициализации каркаса проиндексировать проект через `codebase-memory`.

## Модель данных
```ts
type PaymentType = 'annuity' | 'differentiated';
type Strategy = 'reduceTerm' | 'reducePayment';

interface LoanInput {
  propertyPrice: number;        // стоимость жилья, ₽
  downPayment: number;          // первоначальный взнос, ₽
  termMonths: number;
  annualRate: number;           // % годовых
  paymentType: PaymentType;
  startDate: string;            // месяц первого платежа
  earlyPayments: { monthIndex: number; amount: number; strategy: Strategy }[]; // разовые
  recurringExtra?: { amount: number; strategy: Strategy }; // регулярная надбавка
}

interface ScheduleRow { monthIndex: number; date: string; payment: number;
  interest: number; principal: number; extraPaid: number; remaining: number; }
interface ScheduleResult { rows: ScheduleRow[]; totalPaid: number; totalInterest: number;
  effectiveTermMonths: number; monthlyPayment: number /*или первый для диффер.*/; }
```

## Правила расчёта (ядро)
- **Аннуитет:** `P = S·i·(1+i)ⁿ / ((1+i)ⁿ−1)`, `i = rate/12/100`.
- **Дифференцированные:** `платёж_k = S/n + остаток·i`.
- **Точность (по AGENTS.md):** все суммы — целые копейки, округление каждого месячного платежа до копейки как в банках, округление только на выводе. Последний платёж корректируется добором.
- **Досрочный платёж:**
  - `reduceTerm` — платёж не меняется, срок пересчитывается итеративно (для аннуитета); последний платёж добором.
  - `reducePayment` — срок прежний, платёж пересчитывается от нового остатка (аннуитетная формула на остаток/остаточный срок).
  - Дифференцированные: пересчёт тривиален (остаток / оставшиеся месяцы).
  - Досрочный платёж не больше остатка долга (кап); регулярная надбавка применяется после планового платежа.
- **Крайние случаи:** ставка 0, взнос = стоимости (кредита нет), нулевой срок, досрочка в первый/последний месяц, пустые списки.

## Этапы (каждый заканчивается рабочей проверкой)
- [x] 1. **Каркас:** Vite+React+TS+Tailwind+shadcn, Biome, Vitest, светлая/тёмная тема с переключателем в шапке. Обновить AGENTS.md разделом «Команды» (dev/build/lint/test).
- [x] 2. **Ядро расчётов + тесты:** `lib/calc` полностью, без UI. Эталоны: аннуитет на известных банковских примерах; инварианты — сумма тела = сумме кредита, остаток не уходит в минус, экономия при досрочках = разность переплат. Фундамент — принимается только с зелёными тестами.
- [x] 3. **Форма калькулятора:** поля (стоимость, взнос ₽/%, срок годы↔месяцы, ставка, тип платежа, дата старта), валидация, пресеты льготных программ чипсами (редактируемые, хранятся в localStorage), живой пересчёт. Сводка: платёж, переплата, общая выплата, срок с учётом досрочек.
- [x] 4. **Таблица платежей:** пагинация по годам, колонки месяц/дата/платёж/проценты/тело/досрочный/остаток, подсветка месяцев с досрочными, итоги.
- [x] 5. **Досрочные платежи UI:** редактор-таблица (добавить/удалить разовые: месяц+сумма+стратегия), поле регулярной надбавки со стратегией.
- [x] 6. **Графики:** остаток долга (линейный, точки-отметки досрочек), состав платежа (stacked bar по годам), структура выплат (pie).
- [x] 7. **Сравнение сценариев:** текущий + до 3 снимков, таблица ключевых метрик, наложение графиков остатка, блок «экономия против текущего».
- [x] 8. **Сохранение:** история в localStorage (до 30, авто-имена вида «22 % • 20 лет • 10 млн»), ссылка-шаринг (кнопка «Ссылка», восстановление из `?s=`, поддержано и на /report).
- [x] 9. **Экспорт:** XLSX (лист «Параметры» + «График платежей» с числовым форматом и итогами, динамический импорт exceljs), PDF через печатную страницу `/report` (фиксированная светлая палитра, `@media print`, поддержка `?s=`).
- [x] 10. **Полировка:** адаптив проверен в GUI на 390×844 (фикс `minmax(0,1fr)` + `min-w-0`), пустые состояния, тултипы графиков, компактные подписи осей. A11y-база от shadcn (роли, aria-label, фокус).
